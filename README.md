# Frente de Aço

Combate de armas combinadas da Segunda Guerra no navegador: tanques e aviões na mesma batalha, com física e balística realistas e jogabilidade arcade, no estilo do War Thunder.

## Rodar

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # testes unitários
npm run build    # gera dist/
```

## Destaques

- **Tanques**: M4A3 (76) W, T-34-85, Pz.Kpfw. IV H, Tiger H1 e o antiaéreo Wirbelwind. Corpo rígido (Rapier) com suspensão por roda, tração por lagarta, câmbio com RPM, reparo com F.
- **Aviões**: P-47D, Il-2 e Fw 190 F-8, com modelo de voo 6DOF (sustentação, arrasto, estol, compressibilidade, G e blecaute), bombas, foguetes, flaps e freio aerodinâmico.
- **Balística**: arrasto, queda, perfuração por velocidade (De Marre), chapa inclinada, normalização, ricochete, estilhaços por componente e câmera de impacto em raio-X.
- **Interface**: hangar com análise de blindagem, pontos de spawn (SP), HUD com estado do veículo, configurações com controles remapeáveis (padrão War Thunder), gráficos, áudio e assistências.

## Controles padrão

| Tanque | | Avião | |
|---|---|---|---|
| W A S D | dirigir | mouse | aponta o avião |
| Botão esq. | canhão | W / S | potência (segure W em 100% = WEP) |
| Espaço | metralhadora | A / D · Q / E | rolagem · leme |
| Shift | mira do atirador | Botão esq. | armas |
| Botão dir. | zoom | Espaço · R | bombas · foguetes |
| 1 2 3 | munição | F · H | flaps · freio aerodinâmico |
| F · 6 | reparar · extintor | C | olhar livre |
| E / Q | controle de cruzeiro | | |

Tab placar, M mapa, Esc menu. Tudo remapeável em Configurações.
